常见问题

Halo TV 收费吗？

Halo TV 免费分享，打赏完全自愿。

无法打开 GitHub 或下载失败怎么办？

电视端优先官网下载，失败后尝试 GitHub；也可从官网下载对应 APK，再通过手机推送、U 盘或 ADB 安装。独立版在线更新已同步到 3.2.7。

独立版守护为何仍回原桌面？

旧包的授权不会自动继承。请检查独立版无障碍实际绑定、通知使用权、受限设置及厂商自启动，并避免两套守护同时接管。从 3.2.4 起已移除迁移交接功能，请按当前独立版重新检查实际权限与绑定状态。也提供独立版守护工具；厂商限制仍需对应授权。

可以安装在所有电视上吗？

不同系统、厂商固件和遥控器存在差异。三星 Tizen 和 LG webOS 不属于 Android TV，不能直接安装 Android APK。
