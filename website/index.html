把后台音乐、手机上传和更新进度放到电视桌面。Standard 和 Guard 可选左下、顶部居中、右上，随 Dock 的玻璃样式显示。

软件下载

在桌面查看更新下载进度。

如何开启

在「HaloTV 设置 → 桌面灵动岛」打开开关。显示音乐时，授予「Halo TV 桌面守护」通知使用权，选好「音乐来源 App」，在音乐 App 开启后台播放后按 Home 回桌面。使用有声动态壁纸时，建议关闭壁纸声音。

灵动岛默认关闭。网易云音乐已有真机测试，QQ 音乐和其他播放器需要通过安卓媒体会话提供歌名与播放状态。Lite 同步升级，沿用原有功能范围。

GET STARTED

安装，从这里开始。

安装前，请先在电视网络设置中查看设备系统版本和 IP 地址。

01 · 选择版本

确认设备

普通 Android 电视先试 Standard；安装受限制时可参考 Guard 的说明。旧版 Android 设备可查看 Lite。

02 · 安装

U 盘或 ADB

把安装包复制到 U 盘后在电视打开，或在电视开启调试后，由电脑通过同一网络连接安装。

03 · 完成设置

按设备引导操作

先打开应用确认正常运行，再根据电视系统和个人需要设置默认桌面与相关权限。

常见问题

Halo TV 收费吗？

Halo TV 免费分享，打赏完全自愿。

无法打开 GitHub 或下载失败怎么办？

电视端优先官网下载，失败后尝试 GitHub；也可从官网下载对应 APK，再通过手机推送、U 盘或 ADB 安装。独立版在线更新已同步到 3.5。

独立版守护为何仍回原桌面？

旧包的授权不会自动继承。请检查独立版无障碍实际绑定、通知使用权、受限设置及厂商自启动，并避免两套守护同时接管。从 3.2.4 起已移除迁移交接功能，请按当前独立版重新检查实际权限与绑定状态。也提供独立版守护工具；厂商限制仍需对应授权。

可以安装在所有电视上吗？

不同系统、厂商固件和遥控器存在差异。三星 Tizen 和 LG webOS 不属于 Android TV，不能直接安装 Android APK。
