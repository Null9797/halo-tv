3.5 新功能 · Standard / Guard

桌面灵动岛

显示后台音乐、手机上传和更新下载进度。可放在左下、顶部居中或右上，默认关闭。

如何开启

进入「HaloTV 设置 → 桌面灵动岛」。显示音乐时，授予「Halo TV 桌面守护」通知使用权，选择音乐来源 App，并在播放器开启后台播放。使用有声动态壁纸时，建议关闭壁纸声音。

网易云音乐已有真机测试。其他播放器需通过 Android 媒体会话提供歌名与播放状态。

按习惯安排桌面

自定义应用图标、玻璃 Dock 和遥控器焦点；时间、天气、农历可按需显示并调整位置。

为家人留一个模式

儿童模式可设应用名单和观看时长，支持趣味答题。长辈模式提供大图标和休息提醒。

手机与电视互联

同一网络扫码设置，上传壁纸、视频和应用图标，也可推送通过校验的 HaloTV 安装包。

常见问题

我的电视可以安装吗？

HaloTV 面向 Android TV 设备。具体表现因固件而异。使用 Tizen、webOS 等其它系统的电视无法直接安装 Android APK。

在线更新失败怎么办？

选择与电视上当前类型一致的 APK，可以通过手机推送、U 盘或 ADB 安装。也可使用上方提供的 GitHub 备用下载。

能和 Aerial 一起安装吗？

独立版可以与 Aerial 共存，权限与数据各自独立。建议同一时间只启用一个桌面守护。旧包无法通过独立版直接覆盖，3.2.4 起移除了旧版配置导入。

HaloTV 收费吗？

HaloTV 免费下载和使用，打赏由用户自愿决定。
