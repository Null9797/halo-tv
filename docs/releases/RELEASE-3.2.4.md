# HaloTV 3.2.4 正式版 · 整合 Aerial 1.98，专注独立版

本次为正式发布版，提供 Standard、Guard、Lite。沿用独立版包名和发布签名，Standard / Guard 内部号 **222**，Lite **78**，可覆盖同类型的现有独立版。功能代码沿用本轮已检查的测试版，内部号提升以支持测试版覆盖升级；启动图和 Logo 不变。

## 独立版精简

- 移除旧版/过渡版的配置导入、迁移引导、跨包安装和启动跳转。
- 移除守护交接、让出控制权及相关迁移判断；残留迁移标记不再阻止独立版启动、守护或按键处理。
- 清除手机页面的过渡版说明及废弃迁移组件，Lite 同步清理生成文件。
- 更新统一校验当前包名、独立版发布签名、Standard / Guard / Lite 类型和更高内部版本号。
- 保留当前独立版自身的设置、上传素材、在线更新与普通公告能力；旧版私有数据不再提供跨包导入。

## Aerial 1.98 整合

感谢 Aerial 原作者与贡献者。本轮对照官方 1.98 源码整合前台切换稳定判断、极米锁定开机阶段弹窗、小米待机恢复、当贝关机与更新后返回桌面，以及部分当贝/极米/小米信号源兼容。补充华为设置与网络入口、TCL Google TV 背光检测、天气失败诊断和控制中心信号源刷新。

官方 1.98 发布内 Standard / Guard 为 **1.98 / 144**；Lite 实际仍为 **1.30 / 32**，上游该次未更新 Lite。HaloTV Lite 保留自身 Android 4.x 兼容实现及现有功能，不强行加入完整版的高版本系统接口。

## 额外协调与优化

- 关机期间暂停自动恢复，避免恢复逻辑抵消上游的关机安全处理；重新亮屏或新进程启动后恢复正常判断。
- 延迟服务重扫不覆盖期间发生的明确禁用状态，保留用户选择和其他无障碍服务。
- 单独照片、翻页时钟及在线照片屏保释放暂停的视频壁纸层，减少屏保被视频层覆盖及解码器占用冲突的风险；同一视频的连续衔接保留。

## 检查结果与测试范围

三个 Release 构建通过。Standard / Guard 各 **466** 项、Lite **148** 项主机测试通过，共 **1,080** 项，无失败或跳过。Android Lint 无 Error/Fatal，仍有兼容 API、资源等警告。JavaScript 语法、APK 包名/版本/签名、ZIP 完整性、对齐、完整版 dex 元数据及迁移组件清除检查通过。

本次没有运行模拟器或操作电视。实际流畅度、待机/开机守护和厂商信号源仍需真机反馈；不承诺所有电视均已适配。请重点测试重启与唤醒后的守护、应用返回桌面、动态壁纸/屏保切换、儿童答题与家长密码框。

## 下载与升级

3.2.4 已作为最新正式版发布，独立版电视在线更新通道同步升级：官网下载优先、GitHub 备用。也可下载与当前类型一致的 APK，通过手机推送、U 盘或 ADB 覆盖安装。正式内部号 222 / Lite 78，高于 3.2.3 的 220 / 76 和本轮测试版的 221 / 77；测试版用户也可以检查更新并覆盖升级，保留当前独立版数据。

Standard / Guard 最低 Android 5.0，Lite 最低 Android 4.0。Standard 与 Guard 同包名，二选一。3.2.4 不再提供旧包名配置导入；Android 不会跨包名转移私有数据或系统授权。

对应完整应用源码为附件 `HaloTV-3.2.4-source.zip`，不含发布私钥、本机配置或构建缓存。GitHub 自动生成的 Source code 是发布材料仓库快照。文件校验值见 `SHA256SUMS-3.2.4.txt`。
