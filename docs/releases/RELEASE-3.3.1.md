# HaloTV 3.3.1 · 公告与反馈

## 在电视上提交问题

- 控制中心「公告与提醒」更名为「公告与反馈」，保留公告阅读和未读红点，新增「提交问题」与「我的反馈」。Standard、Guard、Lite 三版同步支持。
- 可选择桌面守护、流畅度、壁纸、软件更新、天气、手机互联等问题分类，提交前查看设备型号、系统和应用版本等信息，并自主决定是否附带诊断信息。
- 反馈仅在用户确认后发送；对诊断中的常见地址和密钥字段做过滤。不自动截取电视画面，不常驻上传或后台轮询。

## 手机补充与回复

- 扫码可补充问题描述和最多两张图片，便于说明复现步骤；手机管理页面也增加反馈入口。
- 提交后保存回执，可在「我的反馈」中手动刷新状态，或扫码查看作者回复。失败的提交可重试；重复提交同一回执不会重复建单。
- 反馈服务已启用，记录不作为公开 Issue 发布。请勿主动上传密码、个人资料或其他敏感内容。回执链接请妥善保管。
- 反馈可查询 30 天，过期记录在后续新提交时清理。服务有容量与提交频率限制，繁忙或网络异常时可稍后重试。部分老电视不能直接建立 HTTPS 连接时，可通过手机页面代为提交。

## 升级与验证

Standard / Guard 内部号 **238**，Lite **94**，高于 3.3 正式包（236 / 92）和公告与反馈测试包（237 / 93）。独立包名、发布签名、Logo 与启动图保持不变。请选择当前相同类型覆盖安装，无需先卸载。

三个 Release 构建、**1,220 项主机测试**（Standard 523、Guard 523、Lite 174）及 **8 项反馈服务测试**通过；Lint 无 Error/Fatal，仍有警告。核验 APK 的版本、包名、签名、ZIP、对齐与 dex 元数据。正式反馈服务已验证提交、重复重试、访问控制、补充说明、后台回复及回执读取。本轮未操作电视或模拟器，真机遥控器布局和网络兼容仍需实际使用反馈。

电视进入「控制中心 → 软件更新 → 检查更新」获取新版；官网下载优先、GitHub 备用，安装仍需在电视确认。本次不发送新的远程公告。
