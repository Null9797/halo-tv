# HaloTV 3.5 正式版

## 新增桌面灵动岛

Standard 和 Guard 支持在桌面显示后台音乐的歌名与封面、手机上传照片或视频的状态，以及更新下载进度。灵动岛可放在左下、顶部居中或右上，默认位置为左下，并随 Dock 的玻璃样式变化。功能默认关闭。

**开启方法**
进入「HaloTV 设置 → 桌面灵动岛」，打开「开启桌面灵动岛」。显示音乐时，允许「Halo TV 桌面守护」的通知使用权，在「音乐来源 App」选好播放器，再到音乐 App 开启后台播放，播放歌曲后按 Home 回桌面。使用有声动态壁纸时，建议关闭壁纸声音。

网易云音乐已在一台电视上测试通过。QQ 音乐及其他播放器需通过安卓系统媒体会话提供播放状态与歌名，实际支持因 App 版本和电视系统而异。Lite 同步升级至 3.5，沿用原有功能范围。

## 其他修复与优化

- **航拍画质**。在线动态壁纸和航拍屏保保留「自动」与「1080p」，设备未报告兼容的 4K 解码能力时说明原因。诊断分开显示设备能力、目标画质与实际首帧画质。 [#55](https://github.com/Null9797/halo-tv/issues/55)
- **本地动态壁纸启动**。Android 5/6 上有可用封面时会保留至播放器提交首帧，减少冷开机时短暂露出旧画面的机会。仍待反馈机型验证。 [#58](https://github.com/Null9797/halo-tv/issues/58)
- **音乐与壁纸**。让动态壁纸及静音屏保减少抢占系统音频焦点，便于播放器保持后台播放。
- **桌面守护工具**。修复 Windows 上读取中文 ADB 输出的异常。旧系统可在确认只有主用户 0 后继续修复，并保留已有无障碍服务。 [#59](https://github.com/Null9797/halo-tv/issues/59)

Standard / Guard 内部号 **270**，Lite **118**。同类型独立版可覆盖升级，保留设置与素材。
