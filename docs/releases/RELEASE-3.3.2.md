# HaloTV 3.3.2 · 全新静态欢迎页

## 第一次见面，更清晰简洁

- Standard、Guard、Lite 三版同步采用全新浅色欢迎页：手写「你好」、HaloTV 标识、品牌光环、星芒和地平线，以及对 Aerial 原作者与开源贡献者的致谢。
- 首屏立即完整显示，采用静态展示，按一次遥控器确认即可进入桌面。保留清晰的操作提示、统一左对齐的声明和不同屏幕比例的等比适配。
- 欢迎页完成状态会保存，正常重启和后续版本更新不会反复弹出。此前已完成浅色欢迎页的测试用户，升级后也保留完成状态。
- 保留 3.3.1 的「公告与反馈」及已启用的私密反馈服务；用户仍可主动提交问题、扫码补充描述/图片，并查看作者回复。

## 安装与更新

Standard / Guard 内部号 **241**，Lite **97**，可覆盖同类型独立版及此前欢迎页测试包（239/95、240/96）。沿用独立包名、发布签名、应用 Logo 和系统启动图，升级保留现有设置、上传素材与欢迎页完成状态。

请在「控制中心 → 软件更新 → 检查更新」获取新版，官网下载优先、GitHub 备用；也可手动下载相同类型 APK 覆盖安装，安装仍需在电视上确认。无需先卸载同包名独立版。

## 验证范围

三个 Release 构建及 **1,231 项主机测试**通过；Lint 无 Error/Fatal，仍有警告。核验包名、版本、发布签名、ZIP 完整性、对齐、共享素材及完整版 dex 元数据。原生主机绘制已对照确认，静态首帧与确认的最终设计一致，并验证等待后画面保持静态、一次确认进入桌面及完成状态保存。本轮未操作电视或模拟器；真机字体、遥控器和固件兼容仍需实际使用验证。
