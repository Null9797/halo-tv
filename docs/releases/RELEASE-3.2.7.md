# HaloTV 3.2.7 · 设置卡死与公告完成状态修复

## 设置与原桌面

- 修复退出儿童／长辈模式后，保留的家长密码让应用列表“设置”反复进入验证回调、造成卡死或重启的问题。仅在家人模式实际启用且处于锁定状态时验证设置入口密码；保存的密码无需删除。Lite 同步调整。
- 系统入口探测、守护调用和启动动画设置纳入异常保护。原桌面使用专门的系统入口；守护 HOME 调用失败时可退回直接启动，设置入口不带图标放大动画参数。

## 公告与提醒

- 选择“知道了／不再提醒”后，该条公告标记完成，不再显示在控制中心入口中。
- 仍有其他未读公告，或选择稍后提醒时，入口继续保留。完成状态跨重启和更新源刷新保存；新版公告修订仍可再次提示。
- 保留 3.2.6 的紧凑 Dock，以及此前下载、安装兼容和公告阅读改进。本次不新增远程公告。
