# HaloTV 3.2.3 · 儿童答题与 Lite 信号源兼容修复

提供 Standard、Guard、Lite 三个独立版，沿用独立包名与发布签名。Standard / Guard 内部号 **220**，Lite **76**；可覆盖升级同类型独立版，也高于本轮本地测试包内部号。

## 儿童答题与家长密码

- 增强“确认答案”和“家长”按钮的遥控器焦点：浅金色底、深色文字与明显描边，更容易看清当前操作位置。
- 打开家长密码框时，暂停下层答题页的按键、触摸和焦点恢复，避免焦点留在答题页；取消后恢复原题及已选答案。
- 修复确认键按下、页面变化、抬起时可能误触其他控件的路径；窗口失焦或页面切换后取消未完成的按压。
- 合并尺寸变化带来的重复重建，保留答案选择与提交状态，减少焦点争抢和无响应感。
- 应用外的答题覆盖页提供可用遥控器操作的数字密码键盘，支持删除、错误提示和返回；保留方向键密码支持。
- Lite 同步焦点、密码输入与答案保持改进，选择答案时原地更新控件，避免反复重建整个答题页。

## Lite 信号源兼容

- 改善部分夏普 / MStar 固件的信号源入口识别，保留 Foxconn 入口；对缺少默认类别的厂商页面，改用已确认可访问的组件启动。
- 仅在已识别的系统电视组件内查找可访问的信号源选择页，排除未导出、禁用、权限受限及工厂/调试页面。
- 提供“打开电视信号源选择”和系统设置备用入口；不再因未发现通用接口就直接判定电视没有信号源。
- 成功打开厂商信号源选择页后关闭 HaloTV 控制中心。系统设置入口继续遵循儿童模式的家长验证。

## 检查与适用范围

Standard / Guard 各 **501** 项、Lite **172** 项主机单元测试通过，共 **1,174** 项。三个 Release 构建、Android Lint（无 Error/Fatal，已有 Warning/Hint 保留）、包名与版本、ZIP 完整性、对齐及 v1/v2 签名检查通过。

本次未运行模拟器、未操作电视。反馈夏普电视的具体型号与系统版本未提供；兼容路径通过代码与主机测试验证，实际切换效果仍需该机型确认。答题修复针对已定位的焦点/输入问题，不代表排除所有设备上的卡顿或系统级 ANR。

保留 3.2.2 独立版迁移与守护交接改进。本版不更换启动图，不新增远程公告弹窗。Lite 最低 Android 4.0，Standard / Guard 最低 Android 5.0。
