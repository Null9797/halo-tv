# HaloTV 3.3 · 桌面体验与控制中心优化

## 动态桌面与流畅度

- 优化桌面、屏保和其他应用之间的视频交接：复用可继续使用的播放器，以过渡画面衔接首帧，减少黑屏、闪烁和返回后等待播放的情况。
- 减少控制中心重复合成、过时的画面保存和后台图像处理；按需释放面板资源，优化图标焦点和缓存。Lite 缩略图采用有上限的缓存与后台队列，减少重复加载。

## 控制中心与公告

- 第二排并列显示「HaloTV 设置」与「桌面守护设置」（原「设为主屏幕」）。
- 最后一排左侧「软件更新」，右侧常驻「公告与提醒」。有效未读公告显示小红点；选择知道了／不再提醒后完成该条公告，全部读完红点消失；稍后提醒保留未读状态。
- 本次发布不发送新的远程公告，现有公告源内容保持不变。

## 守护与系统兼容

- 桌面守护设置加入一键开启与修复、逐项权限引导和实际连接状态检查；增强开机、唤醒后的有界恢复，遵守主动关闭及关机状态。
- 只修复确认失效的系统注册，不继承旧包权限、不自动卸载其他桌面或关闭其他应用的服务。需系统确认或电脑授权的权限仍由用户确认。
- Lite 保持 Android 4.0+ 兼容，提供默认桌面和厂商权限设置指引，不含完整版无障碍守护服务。

## 上游整合与其他修复

- 整合 Aerial 1.99 的相关改进（该次上游 Lite 为 1.31）：天气超时与重试、外接音响音量识别、部分设置和信号源入口、视频上传兼容及关机恢复保护。
- 保留 HaloTV 的独立包名、发布签名、Logo、启动图和现有功能；保留原版权及 MIT 许可，安装包补充 MIT/OFL/来源声明。感谢 Aerial 原作者和所有贡献者；HaloTV 非上游官方发行版。

## 升级与验证

Standard / Guard 内部号 **236**，Lite **92**，高于此前正式版及全部 3.2.8 测试包（最高 235 / 91）。选择与当前一致的类型覆盖安装，无需先卸载。Standard 与 Guard 同包名、二选一，最低 Android 5.0；Lite 最低 Android 4.0。

三个 Release 构建及 **1,199 项主机测试**（Standard 516、Guard 516、Lite 167）通过；Lint 无 Error/Fatal，仍有警告。核对签名、包名、版本、ZIP、对齐和完整版 dex 元数据。本轮未操作电视或模拟器，效果和固件兼容仍需实际设备反馈，不承诺全部电视零闪烁或守护永不掉线。

电视进入「控制中心 → 软件更新 → 检查更新」，官网下载优先、GitHub 备用；安装仍需在电视确认。也可通过官网对应 APK、手机推送、U 盘或 ADB 升级。旧包名配置导入已从 3.2.4 移除，不恢复跨包迁移。
