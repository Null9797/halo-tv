# HaloTV 3.3.5

- 新增 Dock 与图标大小：小、默认、大联动调整，电视和手机均可设置。
- 修正切换 Dock 大小时，左上、右上时间信息及状态栏的对齐位置。
- 修复连续更换在线静态壁纸后桌面仍显示旧图、需要重启才更新的问题。
