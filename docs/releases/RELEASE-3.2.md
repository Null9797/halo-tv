# HaloTV 3.2

HaloTV 是基于 Aerial 的独立衍生项目，非上游官方发行版。三个独立版继续使用 HaloTV 包名与签名。

## 儿童模式

- 新增「答题设置」分组，集中设置观看间隔、答题奖励时长、年龄或年级及题目类型。原有观看间隔和奖励设置保留，新增选项默认不限年龄、综合题型。
- 数学、英语和古诗共 2441 道题；英语含单词识义、中文选英文与数字词运算，同一词条两个翻译方向算两题。古诗部分跨年龄段共享，年龄划分是粗略建议，不是课程大纲。
- 新增 120 个词条的双向翻译练习。筛选后优先避开已记录题目；题量较少的分类用完后会重复。学前古诗共 20 题。
- 设置标签支持五种语言；古诗和英汉词义题仍以中文呈现。

## 其他变更

- 在保留 HaloTV 界面、更新源、壁纸与屏保独立设置及守护交接的前提下，选择性整合 Aerial 1.97 的部分设备和设置兼容改动，并保留项目原有定制；并非完整合并上游。
- 改善设置页面选项布局和部分遥控器入口；调整液态玻璃 Dock 的通透效果。针对图片、网络和部分界面路径做代码层面的资源与稳定性处理；没有本版实测帧率数据，不能断言性能提升。
- 修正手机管理地址缺少尾斜杠时资源加载路径，及 Lite 在线 IP 变化后的二维码刷新逻辑。这些并非已证实的手机无法访问问题根因。
- 未加入上游强制 UHD 和存在迁移或用户主动关闭冲突风险的新增守护自动恢复；此前延期的设置焦点优化不包含在本版。

## 安装与验证

Standard / Guard 共用包名 `app.halotv.launcher`、内部版本号 215，二选一；Lite 为 `app.halotv.launcher.lite`、内部版本号 70。版本名均为 3.2。请使用与已安装独立版相同的变体；签名及版本号检查是覆盖升级的必要条件，不保证所有固件的安装和数据保留行为。旧包名用户仍应先安装对应 3.1 过渡版并按迁移指南操作。

Standard / Guard 各 452 项、Lite 104 项本机单元测试通过，三个 Release 构建和静态签名检查通过。题目自动检查覆盖去重、选项、运算及双向翻译一致性；词义和古诗经过人工核对，尚未经专业教学审校。最终 3.2 包未进行电视、Android 4.x 真机、模拟器、真实手机或长期性能测试。厂商守护、安装限制及遥控体验仍需设备验证。
